# Shell-and-tube examination laboratory

Interactive solutions for the approved shell-and-tube exercises in Coulson and Richardson, Volume 6, 4th edition, Chapter 12.

The academic source is the uploaded chapter PDF only. A result is shown only when the printed data and a printed equation are sufficient. Missing properties and unread charts stay marked incomplete.

## Run

```bash
npm install
npm run dev
```

Open the local address printed by Vite. The site entry is `index.html`.

```bash
npm test
npm run build
```
